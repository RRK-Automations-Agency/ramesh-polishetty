PHOTOS FOLDER
=============

1. HERO / HEADER PHOTOS:
   - Hero photos live in Supabase cloud storage
   - Local photos can also be dropped in this folder
   - Example: photos/your-photo.jpg

2. GALLERY PHOTOS (transformations, achievements, powerlifting, coach, clients):
   - Gallery photos are stored in Supabase cloud storage and appear
     on gallery pages automatically
   - Categories: Transformations, Achievements, Powerlifting, Coach, Clients

3. NOTES:
   - Images are resized and compressed before saving
   - This folder is only used for optional local image assets
